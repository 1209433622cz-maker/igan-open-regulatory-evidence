# Private input handling for R7B4B

Completed author records may contain personal contact information, signatures, institutional determinations and unpublished declarations.

- Keep completed records outside the public Git repository.
- Commit only the empty template, schema and machine validation code.
- Do not place signatures, telephone numbers, private emails or institutional evidence files in a release ZIP intended for public distribution.
- A final public release may contain the published-form author names, affiliations and declarations only after the authors approve that exact version.
- The local validation result may record PASS/HOLD and hashes without copying the private evidence itself.
