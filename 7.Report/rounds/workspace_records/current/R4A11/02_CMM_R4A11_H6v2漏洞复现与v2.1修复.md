# CMM R4A11：H6 v2漏洞复现与v2.1修复

日期：2026-09-12

## 1. 目标

H6 只回答一个问题：收到的 2026 female/male SSc summary-statistics 文件是否具备进入 normalization、harmonization 和 coverage audit 的最低可审计条件。它不运行 fine-mapping/coloc，不生成生物学 posterior，也不计算 C1。

R4A10 的 v2 把状态命名为 paper-grade，但独立反例显示该命名超过了实现。v2.1 将 PASS 缩窄为 `FROZEN_REGIONS_INTAKE_READY_FOR_HARMONIZATION`，并让每个可疑分支停在 HOLD、CONDITIONAL 或 DIAGNOSTIC。

## 2. v2.1修复矩阵

| v2 问题 | v2.1执行门 | 失败状态 |
|---|---|---|
| 非数值/NaN/Inf 可漏过 | frozen region effect、SE、P、alleles 严格 finite/range 校验 | HOLD |
| EAF/INFO 坏值不明确 | EAF/INFO 缺失或非法单列统计 | CONDITIONAL |
| rsID 即 anchor | rsID+GRCh38 chromosome+position+allele set；全文件同 rsID 唯一且无冲突 | CONDITIONAL |
| placeholder provenance | 拒绝模板词、NA、URL 空壳；public catalog 必须 `ebi.ac.uk`+数字 GCST；author transfer 独立分支 | HOLD |
| 自算 hash 冒充 expected | 要求独立 checksum evidence artifact、artifact SHA-256、正文包含 expected digest | HOLD |
| bare N 混淆 | 在基础 extraction 前按 `sample_size/cohort_count/ignore` 显式映射 | CONDITIONAL |
| 样本设计宽松 | cases、controls、total 为正整数且精确相加；逐变异 N 为整数、2≤N≤total | CONDITIONAL |
| effect/SE/P 错列 | 两侧正态 P 的 gross coherence sentinel；相差超过 2 log10 或温和 z 对应 P=0 时阻断 | HOLD |
| 全文件结构弱 | chromosome token/GRCh38 bounds、malformed、U+FFFD、NUL/control char 全文件审计 | HOLD |
| 单行区域可 paper-grade | 每区≥100 rows、≥100 unique positions、span≥250 kb | CONDITIONAL |

区域密度阈值只是明显截断 sentinel，**不是正式 coverage PASS**。正式 common-variant、span、credible-set mass 和 LD compatibility 仍在 R4A12 执行。

## 3. Checksum身份边界

v2.1 能证明：

- 输入 bytes 与 metadata 中 expected digest 一致；
- 保存的 evidence artifact 自身哈希一致；
- evidence artifact 正文包含 expected input digest；
- evidence 文件不是 input 或 metadata 自身；
- public-catalog 与 author-transfer 使用不同格式门。

它不能仅凭本地文件密码学证明“该 artifact 真由某个作者或数据库发布”。因此 JSON 中保留人工核对边界：provider page、邮件原件、签名或仓库 manifest 的来源仍须由人确认。程序不会把这个不可验证部分伪装成自动 PASS。

## 4. 测试结果

### 第一轮独立 black-box

独立编写的 A031 hostile suite 最初在修复中间版本发现 19 个 false PASS。它是本轮查漏的重要证据，促成 checksum artifact、target identity、sample design、whole-file bounds 和路径保护继续加固。

### 冻结回归

`test_h6_v2_1.py` 覆盖 73 个用例，包括：

- 合法 plain/gzip/comma/whitespace 输入；
- 核心与 support 字段非数值、非有限、越界和缺失；
- beta/logOR–SE–P coherence；
- bare N 三种语义与小数/负值；
- exact anchors 的缺失、错坐标、错 chromosome、错 allele 和冲突重复；
- 错 build、错 phenotype、错 study、overall、stratum mismatch、ancestry、来源空壳；
- provider checksum evidence、MD5、author transfer；
- 全文件坐标、U+FFFD、NUL、malformed；
- 区域稀疏、duplicate key、诊断截断、路径穿越和输入覆盖。

结果：**73/73 PASS**。

### 终局 hostile QA

在 A031 原始 black-box cases 基础上，对合法 provenance fixture 补入 v2.1 所需 checksum evidence，再次运行 28 个场景。结果：

- expected PASS：1/1；
- expected BLOCK：27/27；
- false PASS：0；
- missed expected PASS：0；
- suite status：PASS。

这次终局复跑不是第二份独立设计的测试，因此报告同时保留最初 A031 结果和最终冻结结果，不把“修改过合法 fixture 的复跑”夸称为完全独立验证。
