1. **接入门从“看起来像数据”改为可审计身份链。** H6 v2.1 将目标 PMID/DOI、SSc phenotype、female/male stratum、analysis type、ancestry、来源类型、provider checksum evidence、全文件结构、样本设计和两个 exact anchors 绑定到同一次判定。

3. **候选竞争不再事后挑选。** 19 个冻结 peak-link genes 加 PDGFB 共 20 个候选全部登记；SYNGR1 为 primary，RPL3/PDGFB 和其余基因在完全相同规则下比较。原论文已报告 female-SSc–SYNGR1 broad-tissue coloc，项目的新颖性只可能来自 immune-cell chromatin-to-expression 的 signal-level refinement。

## 当前最强但有限的分子证据

TenK10K NK/SYNGR1 eQTL CS4 与 FinnGen l2.NK、peak `chr22-39351520-39352777` 的 caQTL CS1 在两个 GRCh38 变异精确重叠：

- `22:39351666:T:A`：TenK10K PIP 0.5；FinnGen probability 0.2006173；
- `22:39351775:G:A`：TenK10K PIP 0.5；FinnGen probability 0.0522868。

这支持预注册 primary triangle，但仍是 exact-CS overlap，不是正式 caQTL↔eQTL 共定位，更不能替代 disease↔QTL 两条边。

## 下一阶段：R4A12

下一阶段冻结为 **R4A12 — Byte-arrival-triggered Harmonization and Coverage Gate**。触发条件是：真实 female/male genome-wide 文件，或完整 chr22/chr6 预注册区域文件，连同 provider metadata/checksum evidence 到达并通过 H6 v2.1。

触发后固定顺序为：

```text
receipt/checksum → H6 v2.1 → GRCh38 normalization
→ pairwise coverage → signed LD/RSS → D0
→ female fine-mapping → D1/E1/M1 → same-signal triangle
→ 20-gene competition → matched male gate → final state
```

在触发前，最短外部路径是使用本包中的作者数据请求草稿；公开入口刷新属于维护，不再作为新的科学阶段。All-8 对 primary 的 rescue 已取消，如以后执行只能作为独立探索性补充。
