## 3. 发现的定义问题
R6A1 的“published DICE control recovery”是基于：
- 同 locus
- 同 gene
- OneK1K source-significant
- TenK10K source-supported
- broad immune class compatible

它没有检查是否恢复原论文的 cell-specific biology。

原论文正文明确：
- ITGAM/ITGAX 与 IRF4/DUSP22 为 monocyte-specific eQTL colocalization；
- ZMIZ1 为 NK-specific eQTL colocalization。

但 R6A1 OneK source-positive：
- IRF4 = CD4_NC
- DUSP22 = CD4_NC
- ZMIZ1 = NK
- ITGAX = NK

因此必须防止把“同基因跨资源可测”写成“已复现 published positive control”。

## 5. 为什么仍值得继续
正控门的职责是验证：
- 同 build / allele harmonization
- dense regional coverage
- coloc implementation
- resource-specific cell resolution

如果 published monocyte signal 在 OneK1K 变弱而 cross-cell signal增强，这属于真实资源差异，不是自动失败。只有在覆盖充分且多个 published controls 都无法得到任何可解释 signal-level support，才需要审查方法。

## 7. 冻结阈值
Robust：
- default PP.H4 >= 0.80
- H4/(H3+H4) >= 0.80
- p12=1e-6 时不转为 H3-dominant

Targeted LD ambiguity：
- H3+H4 >= 0.50
- H4/(H3+H4) >= 0.20
- 尚未 robust

充分覆盖但强 distinct：
- GWAS min P <= 5e-8
- QTL min P <= 1e-6
- 全部冻结 prior 中 H4 < 0.20

弱 QTL 只记 UNINFORMATIVE，不记 biological negative。

## 8. R6A2A 真正的过门标准
当前 round 只准备并纠偏。下一轮本机实际结果后：

- >=2/3 locus 在 published cell class 获得 robust H4 或经 targeted LD 后 signal-level PASS：
  `GO_R6A2B_FULL_24_LOCUS`
- published cell class 不支持，但 >=2/3 locus 在冻结 secondary cell 中出现强 shared signal：
  `CONDITIONAL_GO_CROSS_CELL_REFINEMENT`，不得声称 DICE cell replication
- <2/3 locus 可解释且技术覆盖充分：
  先进行一次 harmonization/窗口故障审查；仍失败才 `HOLD_METHOD_GATE`
