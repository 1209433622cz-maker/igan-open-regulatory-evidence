## 4. 新执行链

### 01 source LD
`01_build_reep3_cd4nc_source_ld.py` 只过滤 R6A2B0 的 REEP3/CD4_NC QTL，要求 exact 980 active donors、BIM A1/A2一致，并保存 donor顺序、variant顺序、standardized A1 dosage、raw signed correlation 和 checksum。

### 02 residual LD
`02_build_reep3_residual_ld.py` 使用 OneK1K 官方 CD4_NC PF50 covariate 文件：
- PF10 = sex + PC1-6 + age + PF1-10；
- PF50 sensitivity = sex + PC1-6 + age + PF1-50。
要求 design full-rank、finite、symmetry、diag=1、dual PSD。

### 03 multi-signal
`03_run_reep3_multisignal.R` 固定：PF10-L5、PF10-L10、PF10-L20、PF50-L10；95% coverage、min abs corr 0.5；固定 ridge 1e-4 处理 float32 numerical negative eigenvalues。

每个可信 QTL component 都分别与 Asian、combined、European disease region 做 signal-specific coloc，固定 p1=p2=1e-4 与 p12=1e-6/1e-5/1e-4。

### 04 final gate
稳定 CS 被预定义为：PF10-L10 的一个95% CS，在 **PF10-L5、PF10-L20、PF50-L10 三个 sensitivity 配置中分别都有 Jaccard≥0.50 的对应 CS**。

Asian component PASS 还必须：
- default PP.H4≥0.80；
- default H4/(H3+H4)≥0.80；
- p12=1e-6 时 H4/(H3+H4)≥0.50。
