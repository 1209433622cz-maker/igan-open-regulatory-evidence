# GCST009131 接入验收与 R4A6 目标

## 来源与完整性

[官方目录](https://ftp.ebi.ac.uk/pub/databases/gwas/summary_statistics/GCST009001-GCST010000/GCST009131/)

文件 Lopez-Isac_prePMID_META_GWAS_SSc.meta.txt，472,336,600字节，官方MD5匹配。README说明14项European GWAS，9095病例、17584对照、总26679人。目录和README/MD5原文已归档。

全表有4,723,365行，与4723365预期比较见overall_qc.json。原始列为：CHR / BP / SNP / A1 / A2 / N / P / P(R) / OR / OR(R) / Q / I。

## 技术瓶颈

- A2为?：4,723,365行。缺失另一个等位基因使双等位匹配、回文处理和indel核对无法直接完成。
- N分布：{"3": 427804, "2": 413414, "4": 329171, "6": 455062, "7": 314595, "12": 394507, "11": 305078, "5": 379098, "8": 283767, "10": 254481, "13": 520801, "9": 258458, "14": 387129}。按[PLINK官方.meta格式](https://www.cog-genomics.org/plink/1.9/formats#meta)，N是有效研究数，不是样本数。禁止把它传给coloc/susie当N。
- P为fixed-effects，P(R)为random-effects；OR和OR(R)相应分列。不能交叉使用两套值恢复SE。
- 没有SE、EAF、INFO、逐变异N。OR=1.0000共有4,527行，说明打印精度可能影响log(OR)/z近似SE；不能直接填0标准误。
- README不声明坐标build；本轮保留UNCONFIRMED_SOURCE_COORDINATES，不按现代GRCh38坐标直接拼接。提取chr22 38–42Mb和chr6前2Mb仅为宽窗源坐标诊断，共7,314行，并非已harmonize区域。
- 当前没有匹配LD，不把外部任意欧洲LD称为匹配通过。原始OR可记录，但未计算正式PP4。

## 下一阶段执行顺序

1. 首选接入2026 female区域数据及正式字段字典，male随后用于性别比较。已有请求草稿可复用，本轮未发送邮件、未登记表单。
2. 对overall文件，核对作者方法/参考版本，利用可靠双等位参考恢复候选区域A2并记录多映射、回文和不匹配；无法唯一恢复则排除，不凭A1猜A2。
3. 优先获取原始SE/EAF/逐变异样本量。若只能用OR和P恢复近似SE，须单独标记工程敏感性方案，处理OR≈1和极端P、固定/随机模型一致性，并与高精度样本验证；不能称为原始SE。
4. 锁定实际共同变异后再选择LD并检查顺序、方向、覆盖和矩阵性质；QTL端CS输出不等同完整Bayes factors。
5. 全部技术门槛满足后运行有界overall多信号验证；结果仍不能授权female-specific主张或R4B。

本轮接入验收：DOWNLOAD PASS / SCHEMA AUDIT COMPLETE / HARMONIZATION BLOCKED / LD NOT_RUN / COLOC NOT_RUN。比“数据可下载即可跑完整管线”的旧计划更明确。
