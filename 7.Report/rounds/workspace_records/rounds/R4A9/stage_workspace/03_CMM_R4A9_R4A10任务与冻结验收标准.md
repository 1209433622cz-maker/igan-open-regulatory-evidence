# CMM R4A9：R4A10 / H6 下一阶段任务与冻结验收标准

日期：2026-09-10

## 1. 下一阶段名称

**R4A10 / H6 — Sex-specific SSc Intake and Extension-only Gate**

“Extension-only” 的含义是：SYNGR1 的 broad-tissue eQTL 共定位已经由原论文发表；下一阶段必须先复现它，再证明本项目新增的 cell-resolved chromatin-to-expression 层。不能把已发表结果重新包装为新发现。

## 2. 输入优先级

### 必须输入

1. female SSc 全基因组或 chr22/chr6 完整区域 summary statistics；
2. male SSc 对应文件，用作预定义性别对照；
3. data dictionary、精确 genome build、effect/non-effect allele 语义、effect scale；
4. beta/log(OR) 或 OR、SE、P；
5. EAF、imputation INFO；
6. per-variant N、有效 N 或 contributing-cohort count；
7. 下载 URL/访问编号与 provider checksum；
8. 若可提供，cohort-level summary 或 cohort participation matrix。

### 已冻结的 QTL 资产

- GTEx v8 whole blood 与 EBV-transformed lymphocytes：用于复现原论文正控。
- FinnGen/CASCADE immune eQTL、caQTL、peak→gene：用于新增机制层。
- TenK10K SYNGR1 eQTL SuSiE CS：用于跨资源分子复核。
- 1000G Phase3 v5a EUR：仅在 ancestry/build/LD 兼容门通过后使用。

## 3. H6 intake gate

先运行 `h6_intake/RUN_H6_INTAKE.ps1`。它流式扫描大文件并只导出 IRF4 与 chr22 冻结窗口，不复制完整下载文件。

### PASS_PAPER_GRADE_INTAKE_READY_FOR_HARMONIZATION

必须同时满足：

- 至少一个来自 provider 或可信冻结副本的 SHA-256/MD5 checksum 一致；若两者均给出则均须一致；
- source URL 与 accession/provider 可追溯；
- assembly 明确且与本工具冻结的 GRCh38/hg38 窗口一致；
- chromosome、position、effect allele、other allele 或 REF/ALT 完整；
- `effect_scale` 明确为 `beta`、`log_odds` 或 `odds_ratio`，且与 beta/OR 列一致；
- beta/OR、SE、P 每行完整且数值范围合法；
- EAF 与 INFO 每行存在且范围合法；
- per-variant sample size/cohort count 存在；仅在 provider 明确声明所有变异固定 N、case/control/total 可核对时，才允许用全局样本设计替代；
- IRF4 与 chr22 两个冻结窗口均有记录，区域内无重复 locus+allele key；
- 无列映射歧义或格式坏行。

`--max-rows` 只用于诊断，永远不能产生 paper-grade PASS。

这个 PASS 只允许进入 harmonization，不允许直接运行 coloc。

### CONDITIONAL

核心 effect/SE/P/allele 可用，但 EAF、INFO、逐变异样本设计或其他支持信息不完整。必须先向数据提供方补齐，或形成明确的敏感性与缺失字段方案。全局 case/control counts 而无逐变异 N/cohort count 或固定 N 声明属于本级，不能直接 PASS。

### HOLD

缺 SE、核心字段任一行缺失、缺对偶等位基因、effect scale 不一致、非 GRCh38/hg38、缺可信 checksum 或 checksum 不一致、任一目标窗口为空、区域重复 key 或格式错误。不得从 P 与 OR 静默反推后继续主要分析。

## 4. R4A10 分析顺序

### D0：复现原论文 SYNGR1 正控

1. 按 rs66578187 ±500 kb、GTEx v8 whole blood 与 EBV-transformed lymphocytes 构造共同变异集。
2. female 与 male 分开，记录 allele harmonization、共同 SNP 数、区域覆盖与 priors。
3. 先用与原文描述一致的单因果 COLOC；因原文未报告 priors，默认值与敏感性网格必须同时报告。
4. 结果分类：
   - `REPRODUCED`：女性高 PP4、男性低 PP4，且对合理 priors 稳健；
   - `DIRECTIONALLY_CONSISTENT`：性别排序一致，但绝对 PP 受 variant set/priors 影响；
   - `NOT_REPRODUCED`：在覆盖与 harmonization 充分时女性证据不成立；
   - `NOT_COMPARABLE`：输入或方法信息不足。

不要求机械复刻 `0.977/0.980` 到小数位，因为原文没有公开完整输入和 priors。

### D1：新增 disease↔caQTL 主检验

冻结 primary cell 为 NK；CD8 TEM 为 secondary cell。对目标 peak：

- 先做共同变异覆盖和 allele/build 规范化；
- 先跑 LD/kriging compatibility；
- 兼容时运行 multi-signal disease fine-mapping 与 coloc；
- 不兼容时停在诊断层，不删 outlier 或筛高覆盖变异制造 PASS。

这是相对原论文最关键的新结果。

### M1：caQTL↔eQTL coherence

对 FinnGen caQTL 与 FinnGen/TenK10K SYNGR1 eQTL：

- 比较完整可测试变异集，不以两个 CS 交集替代正式分析；
- 报告每个信号的 CS、共享后验、LD 与 variant coverage；
- 不把不同资源的 CS 编号视为可对应标签；
- 评估 NK 优先是否超过其他已覆盖细胞，而非只展示最强细胞。

### G1：候选基因竞争

SYNGR1 为冻结主候选；RPL3、PDGFB 和 source-linked bounded genes 必须在相同 variant/window/coverage 规则下比较。`NOT_RETURNED`、`NOT_TESTED` 与统计阴性分开记录。

### S1：性别对照

male summary 是必要对照。只有女性 shared signal 明确、男性在可比覆盖下不支持，才可使用 “female-predominant” 或 “female-specific regulatory mechanism”。样本量差异必须进入敏感性解释。

## 5. 修订后的 C1 定义

C1 必须同时满足：

1. female disease↔SYNGR1 eQTL 形成可解释的 signal-level shared signal；D0 对原文单因果 COLOC 的 `DIRECTIONALLY_CONSISTENT` 只算正控信息，不能单独计入 C1；
2. female disease↔target caQTL 形成新 shared signal；
3. target caQTL↔SYNGR1 eQTL signal coherence；
4. source-defined 或独立重建的 peak→SYNGR1 link；
5. cell identity、build、allele、LD、coverage、priors 全部通过；
6. male 对照与 power 差异得到解释；
7. 候选基因竞争没有更符合完整证据链的替代解释。

在完成前，`C1_count=null`，不能改成 0。

## 6. 阶段出口

### GO_R4B

chr22 至少形成一个完整 C1，且主要结论在 priors、window、LD 与多信号模型中稳健。之后才启动组织验证与 Figure 主线。

### HOLD_EXTERNAL_ACCESS

female/male 数据仍不可获得。保存当前分子结果并周期性重跑 Catalog 检查；不扩大计算。

### HOLD_TECHNICAL_INCOMPATIBILITY

数据取得但 LD/RSS/coverage 不兼容。优先请求 cohort participation 或一致覆盖文件，不通过删除变异制造结果。

### PIVOT_NOVELTY_INSUFFICIENT

若新增 disease↔caQTL 或细胞型机制不能成立，则该项目只剩对已发表 SYNGR1 共定位的注释性重复。停止组织扩展，返回 Sjögren/MG 备选池或重新筛选有真实独立问题的数据集。

## 7. 扩展限制

- IRF4 为第二链，只在同一 female/male 文件通过 H6 后并行处理。
- all-8 rescue 只有在 chr22 与 IRF4 获得充分数据且均无新增机制信号时才讨论。
- 2019 overall GCST009131 不得替代 sex-specific 主分析。
- Nature Immunology 已覆盖 SSc 与组织驻留免疫 eQTL 的广义整合；“SSc + immune eQTL”本身不是主创新。
