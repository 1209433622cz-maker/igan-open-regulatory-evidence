## 三、实际执行步骤

### 1. 资产清点

- 清点 `R4A8B_IGSR` 全部源文件、脚本、日志和结果。
- 读取 reference gate、harmonization、LD、RSS、H3/H4 根因诊断与 H5 access gate。
- 确认 WSL 中存在 PLINK2、bcftools、tabix；本地存在 Python、NumPy/SciPy、R 4.6.0、susieR 0.14.2。

### 2. 源文件字节审计

- 对 1.216 GB chr1 VCF 计算 MD5 和 SHA-256。
- 对保留的原始 TBI 计算 MD5 和 SHA-256。
- 用 Zenodo 3359882 公布 MD5 进行外部校验，两项完全一致。
- 解析 VCF header，确认 hs37d5/GRCh37 来源。

### 3. 人群与区域文件审计

- 解析 2,504 人 1000G panel，独立筛出 503 EUR。
- 比较 panel EUR、`EUR.samples`、FAM、区域 VCF sample columns 的集合与顺序，全部相同。
- 流式读取区域 BGZF VCF，验证所有 27,067 行为目标窗口内的双等位 SNP。
- 将 CHROM/POS/ID/REF/ALT 与 manifest 逐行比较，完全相同；无缺失或重复 rsID。

### 4. PLINK2 第三方剂量复核

- 从冻结 `IL12RB2_order.tsv` 生成 1,555 个 rsID 的 extract 列表和逐变异 GWAS-A1 allele 列表。
- 用 PLINK2 `--export A include-alt --export-allele` 导出剂量。
- 直接解析区域 VCF 的 GT 字段，按 REF/ALT 与 GWAS A1 独立生成 `503×1555` dosage，并与 PLINK2 BED 输出逐单元比较：最大差 0，缺失模式完全一致。
- 解析 PLINK2 列头，确认 1,555 个 counted allele 全部等于 GWAS A1。
- 比较 PLINK2 与原自写 BED 解码的 `503×1555` 剂量矩阵：最大差 0，差异单元 0。
- 用独立 `numpy.corrcoef` 生成 signed-LD，与冻结矩阵最大差 `6.99×10^-15`。

### 5. RSS 独立复算

- 以 R/susieR 重新读取冻结 z 与 LD。
- 复算 `estimate_s=0.1917849224`、最大 residual `5.361425644`；与原 kriging 最大差 `4.88×10^-15`。
- 复算 `N_STUDIES=14` 与 residual–coverage 关系，重现 H3/H4 结论。
- 坚持预冻结门槛；未运行 SuSiE-RSS，未删除 outlier，未改变 nominal n 制造 PASS。

### 6. 正式数据入口实测

- 同一时间查询 GWAS Catalog v2 publication、study、full-pvalue endpoints，另查旧 API。
- 用 GCST009131 验证 API 正常。
- 按 Systemic sclerosis 查询所有 full-summary studies，只见 2019 overall 数据。
- 保存原始 JSON、OpenAPI 参数快照和可重跑脚本。
- 修正 access 状态机：仅有 PMID study record 不再输出 GO；必须同时出现 full-summary record 和下载入口，才进入字节下载与 H6 验证阶段。

### 7. 官方附件清点与 PDF 视觉核对

- 通过 Europe PMC official supplementaryFiles endpoint 下载附件 ZIP。
- 校验 `mmc1.pdf` MD5 与 PMC XML 完全一致。
- 清点 11 个 ZIP members，确认无 summary-statistics 表格或数据文件。
- 用 Poppler 渲染并视觉检查 Supplementary Table 2；确认 chr22/SYNGR1 两行 PP 与文本提取一致。
- 同时视觉检查原论文候选基因图表，确认 SYNGR1 已被列为 chr22 候选并带 eQTL 注释。

### 8. 新颖性修订

- 废止 “first discovery/reassignment to SYNGR1” 主张。

### 9. H6 大文件接入工具

- 编写流式 summary-statistics intake 脚本，支持 gzip/bgz/bz2/xz/plain 与 tab/comma/whitespace。

## 四、调试与修正记录

1. Python 直接调用 `wslpath` 时，Windows 反斜杠在当前 WSL 命令行组合中被吞掉。已改为可审计的 drive-letter→`/mnt/<drive>/...` 映射；随后 PLINK2 全量导出通过。
2. RSS 首次断言使用 `1e-10` 对比旧 JSON 的高精度值。冻结 TSV 的 12 位输出产生约 `2.1×10^-9` 的预期舍入差。断言改为 `1e-7`，同时保留 kriging 逐值最大差 `<1e-10` 的严格检查。该修正不改变 gate 判定。
3. R 启动出现 `C.UTF-8` locale 警告，susieR 触发 ggplot2 `aes_string()` deprecated warning。两者不影响数值输出；版本与 sessionInfo 已保存。
4. Web PDF screenshot 超时后，改用官方 PDF 字节和 bundled Poppler 本地渲染，完成视觉核验。
5. 最终 QA 发现早期 H6 状态判定可能忽略核心字段逐行缺失、空目标窗口、重复键、未冻结 checksum、错误 build 与 `--max-rows` 截断。发布前补齐硬门并扩展失败测试，旧的两测试 PASS 不再作为充分验收。
6. 最终 QA 还发现 accession 一旦出现就会过早标记 `GO_TARGET_CATALOG_RECORD_FOUND`。已改为分层状态：无记录、仅 study、full-summary 无入口、以及可下载入口待 H6 验证。
