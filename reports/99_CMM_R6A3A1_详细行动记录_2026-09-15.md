## 3. 代码审计和修正

真实 Sun permutation 文件字段证明，protein-encoding Ensembl ID 位于 `molecular_trait_object_id`，adjusted source significance 位于 `p_beta`。原脚本没有识别前一列，也没有把后一列用作门控；候选输出还会纳入同一基因的非显著 probe。修正后只允许 adjusted-P<0.05 或 source CS 存在的 trait 进入稠密分析。

首次 `coloc.bf_bf` 运行还暴露了第二个关键错误：结果的 `hit2` 是 top variant，不是 L component。原裁决会把所有 source CS 错误标为缺失。本轮改用 `idx2→L1…L10`，并重新运行独立 component 裁决。

组织脚本原先把所有 3,620 个细胞送入 kidney marker localization。本轮从 SOFT 逐一匹配 cell title，保留 2,785 个 kidney cells，排除 835 个 peripheral monocytes。另修正负链 indel reverse-complement、Rscript 路径和大文件断点下载。

新增 `00_segmented_fetch.py` 以 8 路 HTTP byte ranges 下载不可变公开文件；每段验证期望长度，组装后验证总字节数。新增 `14_build_r6a3a1_independent_qa.py` 作为不依赖机器终裁 JSON 的独立复核。
