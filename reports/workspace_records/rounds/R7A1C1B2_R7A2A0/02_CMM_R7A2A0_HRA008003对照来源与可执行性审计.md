**日期：2026-09-28**

## 1. 官方样本映射

HRA008003 共 20 个公开 BAM。官方 run/sample 页与论文样本设计共同确定四个连续组：

| runs | 组别 | 组织 |
|---|---|---|
| HRR1849444–9448 | healthy controls | PBMC |
| HRR1849449–9453 | PBC | PBMC |
| HRR1849454–9458 | hepatic hemangioma non-lesion controls | liver |
| HRR1849459–9463 | PBC | liver |

本轮冻结的对照只包含 `HRR1849454–9458`。样本页分别标记为 `control_liver1–5`，标题为 hepatic hemangioma 患者的 normal peritumoral tissue。

## 3. 处理矩阵审计

论文 Supplementary Data 提供 pooled marker、DE、cell abundance 等汇总表，但没有供者级细胞×基因 count matrix 或 barcode-level annotation。轻量表中 FCRL3 是 human liver Naive B 与 Memory B marker；IL12RB2 的唯一补充表命中来自小鼠 NK，不能代替人 PBC/对照供者级比较。

因此 R7A2A1 必须复用公开 BAM。当前最小充分方案只重建两个预冻结 target 和同一 marker gate，不先重建全转录组矩阵。

## 4. 资源决策

H 盘当前可用空间约 758 GiB。runner 按供者下载、校验、扫描、保留 compact output 后删除 BAM，因此空间不是阻塞点。网络与完整扫描会耗时，已按用户既定分工交给本机长任务。
