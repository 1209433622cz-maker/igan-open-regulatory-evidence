## 2. 原包自测与独立 hostile 复核的区别

原包 H6 v2 编译通过，自带 16/16 测试通过。这只能证明它通过了作者编写的 16 个场景。独立构造错误输入后，出现以下可复现 false PASS：

| 漏洞 | 反例 | 风险 |
|---|---|---|
| 核心数值解析失败未传播 | frozen region 中 SE/P/beta 为非数值仍 exit 0 | 错列或坏数据进入下游 |
| lead 只看 rsID | rsID 位于错误 chromosome/position 仍满足 anchor | 不能证明找到 frozen GRCh38 anchor |
| provenance 只看非空 | `REPLACE`、空壳 URL、本地现算 expected hash 可 PASS | 来源真实性被夸大 |
| bare N 迟绑定 | cohort count 被输出为 sample_size；14.5 cohorts 可 PASS | RSS 样本设计错误 |
| whole-file chromosome 未校验 | 区域外非法 chromosome 可 PASS | 全文件结构门与说明不一致 |
| 区域密度缺失 | 每个区域一行即可称 paper-grade | 截断文件被误授权 |

还复现了 target phenotype/overall/stratum 身份未绑定、case/control/total 不自洽仍可推进、effect–SE–P 明显矛盾未发现、`CONDITIONAL` 退出码为 0 等问题。

因此最终审计不是“R4A10 全错”，而是两层结论：

- **release/transfer integrity = PASS**；
- **H6 v2 paper-grade intake claim = FAIL_QA_BLOCKERS**。

## 3. 科学状态复核

R4A10 报告中的静态科学状态彼此一致：`CONDITIONAL_GO`、`R4B=HOLD`、sex-specific summary `NOT_OBTAINED`、chr22 disease signal `NOT_TESTED`、`C1_count=null`。本轮没有证据推翻这些边界。

这里必须区分两件事：H6 v2 软件漏洞不等于既有分子 evidence 失效；它意味着未来真实 female/male 文件不能由 v2 判定。R4A11 已用 v2.1 替换该入口。
