# R7C3 详细行动记录：全量资产核查、公开同步与投稿包

## 任务

用户要求执行一次 GitHub 推送，核查全部本地文件的大小与内容，整理有价值成果及后续可复用内容，保留工作记录，制作投稿包，并判断下一阶段目标。写作继续使用 QiTeng Academic Writing Skill，不使用 CC；Office 视觉凭据沿用 WPS 后台渲染结果。

## 执行动作

1. 查验工作区结构、Git worktree、最新 release 与 R7C2 投稿基线。
2. 对 50,630 个盘点基线文件记录路径、大小、类型、修改时间、公开边界和内容/结构摘要。
3. 对 <=256 MiB 文件直接计算 SHA-256；对 18 个更大文件单独流式补算，最终研究文件哈希无遗漏。
4. 对 122 个研究 ZIP 做 CRC test，对 4,211 个 GZIP 做完整流解压。
5. 统计 top-level、extension、duplicate hash groups、fragment files、large-file receipts 与内容解析异常。
6. 从 202 份行动记录中按内容哈希去重，建立 85 份 canonical record ledger 和全部副本映射。
7. 整理 26 类当前论文、核心数据、方法、治理、记录和版本资产；冻结公开与禁止公开边界。
8. 独立审计 GitHub branch、HEAD、tracked files、manifest、secret pattern、>10 MiB file、license 与 `git fsck`。
9. 从 R7C2 WPS/QA 通过的精确字节构建 npj submission bundle，生成 upload checklist 和 checksum manifest。
10. 生成 R7C3 报告、公开压缩总账、release package、GitHub commit/tag/release 与最终 receipt。
