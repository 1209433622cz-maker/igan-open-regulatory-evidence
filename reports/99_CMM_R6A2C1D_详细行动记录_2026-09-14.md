## 三、执行前代码审计

逐文件检查 PLINK BED 解码、donor 顺序、A1 方向、残差化、LD 顺序、SuSiE 配置、component Bayes factor、coloc priors、CS stability 和最终 gate。

确认 QTL-side signal coloc 使用 SuSiE `lbf_variable`，与 coloc 5.2.3 的 `coloc.susie` 内部选择方式一致；疾病侧使用 case-control Wakefield ABF。发现疾病 lead presence 被错误写成 LD PASS 必要条件，按冻结协议修正为覆盖限制。首次修补使用不存在的 `pos` 列，真实运行立即 KeyError 并停止；改成 `position_GRCh37` 后从第一步重跑。

脚本随后改为支持 `IGAN_PROJECT_ROOT`，方便本机和 GitHub 复现。Python compile PASS；synthetic Jaccard test PASS。

## 四、OneK source-LD 实跑

重新核对 9 个核心输入的 bytes 与 SHA-256。使用 CD4_NC 980 donors，从 5,326,925-variant PLINK 中按 QTL/BIM exact variant identity 提取 3,084 个 REEP3 variants。A1/A2 semantics 全部一致；missing rate 最大值为 0；共享候选 `10:65376395` 在场。

疾病 lead `10:65363048` 不在交集；最近变异 `10:65363166` 距 118 bp。该限制写入 sourceLD_QC，不作为技术失败。

构建 raw、PF10、PF50 correlation；PF10/PF50 design full-rank，残差 df 961/921，无小于 -1e-8 的负特征值。三套大矩阵留在本地结果目录，不上传 GitHub。

## 五、SuSiE 与 signal-specific coloc

运行 R 4.6.1、susieR 0.14.2、coloc 5.2.3。PF10/L5、PF10/L10、PF10/L20、PF50/L10 分别 4、5、7、5 次迭代收敛；每套产生同一个 15-member 95% CS，三项敏感配置对 primary 的 Jaccard 都为 1.0。

Asian PF10/L10 默认 PP.H4=0.9004816、H4 ratio=0.9132185；低 p12 ratio=0.5127463，满足冻结门。combined 与 European 默认 H4=0.0717150、0.0148624。终裁写为 `PASS_ASIAN_SPECIFIC_DISCOVERY_CANDIDATE`，并自动生成 TenK trigger。

## 六、TenK10K targeted replication

先读取本机已有的 10.1 MB gene-level ZIP 与 59.7 MB SuSiE summary ZIP。发现内部文件实际为 comma-separated，修正解析后提取 REEP3：CD4_Naive 与 CD4_TCM 均有显著 gene-level QTL，各有一个 source CS；Treg gene-level 较弱且无 CS。

为取得 disease–TenK QTL 的独立作者结果，复用经过审计的 HTTP Range ZIP parser，从 626 MB coloc archive 只读取中央目录和三个 `kiryluk_IgAN/*/chr10.csv` 成员。三个文件通过 member CRC、长度和 SHA-256；未下载整包，也未声称本地复算 provider MD5。

下载 UCSC hg19→hg38 chain，记录 bytes 227,698 与 SHA-256 `5c0598e500ceb5a78c73086929e8ef993aec309bcafb595139b53d440b125a1d`。OneK primary CS 15/15 唯一映射至 GRCh38 chr10 正链，与 TenK source CS 的 exact position+allele-set overlap 为 0。

TenK author-precomputed IgAN coloc 在 CD4_Naive 与 CD4_TCM 分别为 H3=0.9650/H4=0.0314、H3=0.9687/H4=0.0258。冻结 replication gate 判定 `FAIL_INDEPENDENT_TENK_REPLICATION`。

## 八、项目终裁

REEP3 保留为 OneK Asian discovery-only 结果，不计入 replicated locus。现有多位点 IgAN immune cis-eQTL 主设计只有 ZMIZ1/NK 一个跨资源锚点，因此冻结 full-24 与双位点 ancestry-aware 稿件。

下一阶段冻结为 R6A3A：公开 cis-pQTL 字节级预检 + ZMIZ1 肾组织 donor-level 定位预检。需要至少一个新增独立 pQTL shared-signal locus，同时 ZMIZ1 tissue layer 可解释，才恢复 manuscript-scale analysis；否则归档 IgAN 主项目并换题。
